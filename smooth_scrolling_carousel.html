Copy & Paste CSS Keyframe Code

Drop this snippet into your stylesheet to create infinite marquees instantly.

@keyframes scrollLeft {
  0% { transform: translateX(0); }
  100% { transform: translateX(-50%); }
}

.animate-marquee {
  display: flex;
  width: max-content;
  animation: scrollLeft 35s linear infinite;
}

/* Pause on hover */
.animate-marquee:hover {
  animation-play-state: paused;
}
